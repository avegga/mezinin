# Контекст проекта по б/у мезонинам

Этот файл фиксирует ключевые решения из рабочего чата, чтобы они были доступны прямо внутри проекта.

## Что обсуждали

- Разбор сайта складмск.рф с точки зрения маркетинга, UX и SEO.
- Переупаковку направления компании под более узкую специализацию: б/у мезонины и сопутствующие услуги.
- Смещение акцента с общей складской техники на б/у мезонины как основной продукт.
- Постепенную сборку серии HTML-страниц: от концепта до почти продакшн-макетов.
- Переход от одной главной страницы к SEO-структуре сайта с отдельными внутренними URL.

## Главные выводы

1. Основной оффер должен строиться вокруг б/у мезонинов, а не вокруг широкого каталога складского оборудования.
2. Для конверсии одностраничник может работать, но как единственная SEO-модель он слишком ограничен.
3. Лучший вариант: сильная коммерческая главная плюс отдельные внутренние страницы под разные интенты.
4. Стеллажи допустимо упоминать только как часть комплексной комплектации, а не как главный продукт.
5. На сайте нужен выраженный B2B-стиль: строгая подача, реальные факты, понятные офферы, кейсы, фото объектов, форма заявки.

## Правила, которые были согласованы в чате

1. Каждая новая версия страницы должна сохраняться как отдельный файл.
2. В имени нового файла должны быть дата и время.
3. Главный акцент в контенте: б/у мезонины.
4. Стеллажи и прочая складская техника могут упоминаться только как сопутствующая часть решения.
5. Стиль сайта должен быть ближе к реальному промышленному B2B-сайту, а не к концептуальному макету.

## Следующие логичные шаги

1. Собрать страницу "Б/у мезонины для комплектации".
2. Собрать страницу "Монтаж б/у мезонинов".
3. Сделать шаблон внутренней страницы, который можно тиражировать на весь сайт.
4. После этого собрать навигационный каркас всего сайта и перелинковку между страницами.
