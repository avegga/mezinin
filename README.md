# Проект сайта по б/у мезонинам

Рабочий репозиторий для сборки коммерческого сайта по б/у мезонинам с фокусом на B2B-интенты, конверсионную главную страницу и SEO-структуру отдельных внутренних URL.

## Что внутри

- коммерческая база проекта и зафиксированный контекст в Markdown-файлах;
- актуальная рабочая HTML-страница по интенту "для склада";
- архив предыдущих итераций главной и внутренних страниц;
- шаблон внутренней страницы для дальнейшего масштабирования.

## Ключевые файлы

- `CHAT_CONTEXT.md` — зафиксированные решения по позиционированию и структуре сайта;
- `ROADMAP.md` — порядок выпуска страниц и приоритеты;
- `STRUKTURA_SAYTA_2026-04-19_22-55.md` — архитектура сайта и назначение URL;
- `KARTA_SAYTA_2026-04-19_23-01.md` — краткая карта сайта со статусами;
- `TZ_GLAVNAYA_OT_SKLADA.md` — ТЗ на новую главную страницу;
- `mezoniny-bu-dlya-sklada-2026-04-19_22-35.html` — текущий основной HTML-референс;
- `internal-page-template.html` — базовый шаблон внутренней страницы;
- `Архив/` — предыдущие версии макетов и HTML-итераций.

## Текущий фокус

Проект развивается от общей складской тематики к узкому офферу по б/у мезонинам:

- главная должна продавать б/у мезонины как основной продукт;
- внутренние страницы закрывают отдельные интенты: склад, комплектация, офис, производство, монтаж, доставка, адаптация;
- доказательные разделы усиливают доверие: кейсы, фото объектов, FAQ, контакты.

## Принцип работы с версиями

- новые итерации сохраняются отдельными файлами с датой и временем в названии;
- старые версии не перезаписываются;
- сначала собирается рабочий коммерческий каркас, затем страница усиливается кейсами, FAQ, фото и перелинковкой.

## Ближайшие задачи

1. Усилить главную страницу под конверсию.
2. Выпустить страницы для комплектации, монтажа и офисного сценария.
3. Дособрать доказательные страницы: кейсы, FAQ, контакты.
