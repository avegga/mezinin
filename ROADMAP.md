# Roadmap По Разработке Сайта

Этот файл задает очередность разработки страниц и помогает выпускать новые разделы без потери приоритетов.

## Принципы

1. Каждая новая версия страницы сохраняется отдельным файлом с датой и временем.
2. В первую очередь собираются страницы с самым сильным коммерческим и SEO-потенциалом.
3. Сначала делаем каркас коммерческих страниц, потом усиливаем их кейсами, фото, FAQ и региональностью.
4. Главный продукт сайта: б/у мезонины. Сопутствующие решения показываются только как часть проекта.

## Этап 1. Основа проекта

Статус:
- завершено

Что входит:
- позиционирование под б/у мезонины
- продакшн-версия главной
- форма заявки
- галерея
- SEO-структура главной
- внутренняя страница под интент "для склада"

Результат:
- есть рабочая база дизайна, оффера и структуры сайта

## Этап 2. Ключевые коммерческие внутренние страницы

Статус:
- в работе

Очередность:
1. Б/у мезонины для комплектации
2. Б/у мезонины под офис
3. Б/у мезонины для производства
4. Монтаж б/у мезонинов
5. Доставка мезонинов
6. Подбор и адаптация под объект

Цель этапа:
- закрыть основные коммерческие интенты отдельными URL
- убрать конкуренцию смыслов внутри одной страницы
- создать базу для внутренней перелинковки

Критерий готовности каждой страницы:
- hero под конкретный интент
- 3-6 сценариев применения
- блок преимуществ именно для этого направления
- услуги или состав проекта
- кейсы
- FAQ
- форма заявки

## Этап 3. Доказательные страницы

Статус:
- не начато

Очередность:
1. Фото и объекты
2. Кейсы
3. FAQ
4. Цены
5. О компании
6. Контакты

Цель этапа:
- усилить доверие
- улучшить конверсию
- расширить SEO-покрытие за счет вопросительных и доказательных интентов

## Этап 4. Региональная структура

Статус:
- не начато

Очередность:
1. Москва
2. Московская область
3. Санкт-Петербург
4. Нижний Новгород
5. Екатеринбург

Цель этапа:
- закрыть локальный коммерческий спрос
- масштабировать органический трафик там, где реально есть поставка и монтаж

Условие запуска этапа:
- сначала должны быть готовы базовые коммерческие страницы и контакты

## Этап 5. Шаблонизация И Ускорение Выпуска

Статус:
- в работе

Что делаем:
- единый шаблон внутренней страницы
- единые блоки hero, benefits, cases, faq, contact
- единые формулировки для формы и контактов
- повторяемый набор CTA и внутренних ссылок

Цель этапа:
- сократить время выпуска новых страниц
- сохранить визуальную и смысловую консистентность

## Этап 6. Усиление Уже Собранных Страниц

Статус:
- не начато

Что усиливаем:
- микроразметка
- хлебные крошки
- отдельные блоки перелинковки
- локальные FAQ под конкретные страницы
- более точные кейсы по направлениям
- отдельные галереи по интентам

## Приоритет На Ближайшие Выпуски

1. Выпустить страницу "Б/у мезонины для комплектации".
2. Выпустить страницу "Монтаж б/у мезонинов".
3. Выпустить страницу "Б/у мезонины под офис".
4. Собрать единый шаблон и дальше тиражировать новые страницы через него.
5. После этого перейти к страницам "Кейсы", "FAQ" и "Контакты".

## Контрольный Список Для Каждой Новой Страницы

1. Отдельный файл с датой и временем.
2. Уникальные title и meta description под интент.
3. Уникальный h1.
4. Уникальные сценарии применения.
5. Уникальные вопросы в FAQ.
6. Актуальная форма с маской телефона.
7. Контакты и адрес компании.
8. Проверка HTML на ошибки.
